# 🎣 Прогноз клёва — PWA

Прогноз вероятности клёва рыбы на основе погодных данных. Работает на любом телефоне через браузер.

## Как запустить (за 5 минут)

### 1. Создайте репозиторий на GitHub
- Зайдите на [github.com](https://github.com)
- Нажмите **New repository**
- Название: `fishing-forecast` (или любое другое)
- **Public** → **Create repository**

### 2. Загрузите файлы
Нажмите **«uploading an existing file»** и загрузите:
- `index.html`
- `app.js`
- `manifest.json`
- `sw.js`

Или через Git (если знаете):
```bash
git clone https://github.com/ВАШ_НИК/fishing-forecast.git
cd fishing-forecast
# скопируйте 4 файла сюда
git add .
git commit -m "Initial"
git push
```

### 3. Включите GitHub Pages
- В репозитории: **Settings** → **Pages**
- Source: **Deploy from a branch** → **main** → **Save**
- Через 1–2 минуты сайт будет доступен по адресу:
  `https://ВАШ_НИК.github.io/fishing-forecast`

### 4. Установите на телефон
**iPhone (Safari):**
1. Откройте ссылку в Safari
2. Нажмите **Поделиться** (квадрат со стрелкой)
3. Прокрутите вниз → **«На экран "Домой"»**

**Android (Chrome):**
1. Откройте ссылку в Chrome
2. Нажмите **⋮** → **«Добавить на главный экран»**

Приложение появится на рабочем столе с иконкой 🎣 и работает офлайн.

## Возможности

- 🔍 Прогноз по любому населённому пункту с автодополнением
- 📊 Почасовой прогноз на 48 часов
- ⭐ Автоподбор лучших слотов для рыбалки
- 🌙 Автоматический расчёт фазы луны
- 📉 Динамика давления и температуры
- 📴 Работает офлайн (кэширует данные)
- 🌍 Корректный выбор города по стране и населению

## Архитектура

| Файл | Назначение |
|------|-----------|
| `index.html` | Главная страница, UI |
| `app.js` | Логика: геокодинг, погода, эвристика, автодополнение |
| `manifest.json` | Настройки PWA (иконка, тема, режим) |
| `sw.js` | Service Worker — кэширование, офлайн |

## API

Используется [Open-Meteo](https://open-meteo.com) — бесплатно, без ключа, безлимитно.
